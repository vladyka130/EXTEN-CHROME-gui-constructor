Кнопка «Дивитись» відкриває живий перегляд: можна клікати по елементах панелі й міняти їх. Файли розширення при цьому не редагуються.

«Сирі» правки файлів інтерфейсу. Логіку (JS-код) краще не чіпати — для текстів є вкладка «Мітки». Перед збереженням робиться знімок.

    


    

      
Щоб панель наповнилась даними в перегляді, тут описують відповіді. Для запиту до сервера JSON — це тіло HTTP-відповіді; для повідомлення фоновіку — рівно те, що розширення отримає у колбек sendMessage (напр. {"ok":true,"data":{…}}). Без моків панель показує свій стан «сервер недоступний» — це теж корисно для оформлення.
